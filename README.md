idk-but-for-u
A minimal static website built to present a concise, focused web experience. The project emphasizes simplicity, clean structure, and lightweight implementation using core web technologies.

🔗 Live Demo:
https://asmitamathur18.github.io/idk-but-for-u/

Overview
This project demonstrates a straightforward frontend implementation without external libraries or frameworks. It is designed to load quickly, remain easy to maintain, and be accessible across modern browsers and devices.

Technologies Used
HTML5 – Markup and structure
CSS3 – Styling and layout
JavaScript (Vanilla) – Client-side behavior

Project Structure
idk-but-for-u/
│
├── index.html      # Main HTML file
├── style.css       # Stylesheet
└── script.js       # JavaScript logic

Getting Started
Run Locally
Clone the repository:
git clone https://github.com/asmitamathur18/idk-but-for-u.git

No additional setup or dependencies are required.
